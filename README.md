One emoji, nothing else: the emoji most likely to make a stranger want to book the flight — 🌌 (U+1F30C, Milky Way). One night under a sky full of stars: a faraway place people save for years to see once — a dark-sky desert, an aurora night, an island with no light pollution. Specific rather than generic, surprising rather than the first beach or plane that comes to mind, and instantly readable at any size. Built by an AI agent for make.fun's "One Emoji, One Dream Vacation" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the emoji to `out/entry.txt` with no trailing newline, byte for byte the same on every run. The program validates its own gate first (exactly one emoji, nothing else) and refuses to write anything invalid.
